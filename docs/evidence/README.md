# 근거와 검토 범위

이 공개 문서는 당시 세션의 관측·보고와 현재 소스 구조를 정리했다. 새 실제 제작 실험이나 전체 정확도 평가를 수행한 문서가 아니다.

## 이번에 다시 확인한 자료

- 기존 비공개 Git 원격의 커밋 메타데이터 8개.
- 사용자가 지정한 9월 작업 세션과 현재 10월 작업 세션의 원시 JSONL 2개. 이 세션들의 사용자 요청과 최종 답변을 직접 추출했다.
- 아래 21개 사례에 연결한 근거 문서 29개 항목. 일부 문서는 두 사례에서 다시 참조한다.
- 최신 kit의 실행 코드, 설치 구조, 문서, 합성 fixture.
- 현재 로컬 `.git/HEAD` 부재와 원격 저장소 상태.

원시 로그는 추출 순간의 길이와 SHA-256을 로컬에 기록했다. 진행 중 세션은 이후에 더 길어질 수 있다. 추출 시점의 접두부 해시를 최신 전체 파일 해시로 표현하지 않는다.

8월의 일부 원시 로그는 이번 로컬 저장소에서 찾지 못했다. 해당 기간은 보존된 세션 보고와 사고 검토를 사용했다. 8월 27일 과거 검토가 74개의 관련 rollout을 6개 논리 작업으로 묶은 기록도 재사용했다. 이번에 74개 원시 로그를 새로 전수 검토했다고 주장하지 않는다.

## 공개 자료와 비공개 원본

[case-index.json](case-index.json)은 사례, 날짜, 원본 식별 key와 해시를 담는다. 원본 key는 공개용 opaque key다. 실제 파일 경로와의 대응은 로컬 검토 기록에 보존했다.

공개 문서에는 문제지 주소, 원본 시험지, 학교·학생 자료, 브라우저 프로필, 계정 자료, 원시 화면을 올리지 않는다. 외부 독자는 요약과 공개 코드를 읽을 수 있다. 비공개 관측을 직접 재현하거나 원본 화면을 열 수는 없다. 해시만으로 요약의 현실 정확성이 증명되지는 않는다.

## 주장을 읽는 기준

| 근거 종류 | 말할 수 있는 내용 | 말할 수 없는 내용 |
|---|---|---|
| 과거 세션 보고 | 당시 결과와 작업 방식 | 현재 저장 상태와 서비스 가용성 |
| 당시 실제 관측 | 해당 시점의 화면·제어·시간 | 모든 브라우저·PC의 일반 성능 |
| 합성 회귀 | 지역 계약의 허용·거부 동작 | 독립 본문 정답과 실제 클릭 성공 |
| 파일 해시 | 자료의 바이트 identity | 그 자료가 묘사한 현실의 정확성 |
| 커밋 기록 | 변경의 순서와 당시 제목 | 변경 후 실제 제작 품질의 인과 효과 |

공개본의 새 검사 결과는 [publication-checks.json](publication-checks.json)에 별도로 기록한다. 이것을 과거 전체 runner의 PASS로 대체하지 않는다.
