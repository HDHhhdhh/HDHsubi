# 공개 회귀 inventory

이 목록은 [실행 manifest](../../scripts/offline-regression-gates.json)와 같은 gate 32개를 분류한다. `public`은 12개, `private-bundle`은 20개다. Phase 0의 공개 gate 11개에 Phase 1의 ValidationContext를 추가했다. 원래 `test_*.ps1` 23개를 빠짐없이 포함한다. 검색 관측의 `All`은 Contract/Collector/CuaRestricted 세 gate로 나눠 모든 분기를 실행한다. 원래 full runner의 문서 검사·kit 검사·fixture 생성·body-exact corpus 검사도 보존해서 표시한다.

`private-bundle`은 실행 준비 등급이다. 모든 파일이 비공개라는 판정은 아니다. 합성 helper도 원본 파일과 공개 승인 근거가 없으면 이 등급으로 둔다. 누락 파일을 다른 자료로 대체하지 않았다. D4 자료가 제공되면 내용과 provenance를 확인한 뒤 등급을 바꿔야 한다.

필요 경로에는 직접 필요한 fixture 파일 또는 원래 registry가 열거하는 묶음의 디렉터리를 적었다. `lessons`, `evaluation`, `docs`, `pdf-pages`, `.omo/evidence`의 개별 파일 목록은 원래 registry/bundle이 있어야 완전히 확정할 수 있다. 없는 파일의 공개 가능 여부를 추정하지 않는다. 실행 코드 모듈은 저장소에 포함되어 있다.

## 실행과 실패 처리

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File ./scripts/run_offline_regression.ps1
```

각 gate는 상태와 경과 시간을 JSON 한 줄로 출력한다. 마지막 줄은 합계다. private-bundle은 이유를 포함한 SKIP으로 출력한다. public 의존성 누락, 비정상 종료 또는 PASS marker 누락은 FAIL이다. 뒤의 gate도 실행하며 FAIL이 하나라도 있으면 종료 코드 1이다. 등록되지 않은 기존 테스트가 생겨도 실패한다.

Python 3.12와 Pillow/reportlab/pypdf, PowerShell 7이 필요하다. YearRangeLocalAdapter는 Windows PowerShell 5.1도 호출한다. CuaRestricted에는 Node가 필요하다. Collector에는 Playwright 1.62.1과 Edge/Chrome 실행 파일이 필요하다. CI는 Node 22와 Playwright를 runner의 임시 폴더에 설치한다. 이 경로는 서비스 로그인 또는 사용자 프로필을 사용하지 않는다.

```powershell
$env:PYTHONUTF8 = '1'
pwsh -NoProfile -File ./scripts/run_offline_regression.ps1 -PlaywrightModule <module-directory> -BrowserPath <browser-executable>
```

Collector는 저장소의 local simulator만 열고 HTTP(S) 요청을 중단한다. 이는 재사용 가능한 합성 회귀이며 수학비서의 live 조작이나 browser 가용성 증명이 아니다. 새 AppendHistoryFixture gate는 원래 helper를 복원한 것이 아니라 공개 계약으로 만든 별도 합성 시험이다. 기존 ProductionValidation/StateMachine/PartialSavePhases 전체 suite는 여전히 SKIP이다.

Phase 0의 연도 테스트 2개는 기존 contract reader로 날짜 문자열의 시간대 정보를 보존한다. Phase 1은 검증 모듈 4개에 호출 단위 캐시와 구조 비교를 추가했다. 이력 fixture의 호출 횟수 단정은 H+1 기준으로 바꿨다. full runner, 설치된 skill 및 AGENTS/SKILL/prompts는 변경하지 않았다. SOURCE_SNAPSHOT의 원본 sourceSha256은 보존하고 변경한 export의 해시·크기·transformation만 갱신한다. 새 시험은 새로 작성한 공개 합성 시험이며 원본 export 파일로 기록하지 않는다.

Phase 1b는 기존 ValidationContext와 AppendHistoryFixture gate에 PDF worker 수명·오류 진단, append 내용·형식·기대 목록 변조와 실제 실행 횟수 검사를 추가했다. gate 수는 12 public / 20 private-bundle 그대로이며, 별도 동일성 비교는 PDF 손상 2종을 포함한 24개 사례다.
