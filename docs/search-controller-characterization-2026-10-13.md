## 별도 삭제 조작 비교 C12

같은 검색어 상태 6개를 전체 삭제 버튼 클릭과 Enter 활성화로 각각 지웠다. 등록한 순서는 3개 AB와 3개 BA다. 12회 모두 전체 삭제 후 실제 세 판독에서 빈 칩 상태를 확인했다. 출처는 유지됐다. 개별 칩 제거 복구는 필요하지 않았다.
